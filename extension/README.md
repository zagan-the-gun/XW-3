# 出品くん Filler (Chrome拡張)

XW-3 出品くんに登録した商品データを、メルカリ / Yahoo!フリマの出品フォームへ
**ワンクリックで流し込む**ための自分用Chrome拡張です。

## やること / やらないこと

| | |
|---|---|
| ○ | タイトル・説明文・価格の入力 |
| ○ | 写真(最大20枚)の投入 |
| ○ | カテゴリ(階層)・商品の状態・配送の方法・送料の負担・発送元・発送までの日数の選択 |
| ○ | ハッシュタグ(Yahoo!フリマの専用欄) |
| **×** | **出品ボタンを押すこと** |

最後の確認と出品ボタンは必ず人間が行います。これは規約上のリスク管理として意図的な線引きで、
自動出品(=ボタンまで自動)は行いません。

> なお「入力支援」自体もメルカリ規約のグレーゾーンです(明示的な禁止条文はなく、
> ガイドの「弊社が提供するインターフェイスとは別の手法でのアクセス」という裁量条項の解釈次第)。
> 自己責任でご利用ください。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ(`extension/`)を選択
4. 拡張の「詳細」→「拡張機能のオプション」を開き、XW-3のURL(例 `http://192.168.1.10:8720`)を入力して
   **「保存して許可」**(そのアドレスへのアクセス許可を求められます)
5. 「接続テスト」で商品件数が表示されればOK

## 使い方

1. メルカリまたはYahoo!フリマの出品ページを開く(右下にパネルが出ます)
2. パネルで商品を選び「この商品を流し込む」
3. 結果リストで各項目の成否を確認し、`×` の項目は手動で設定
4. 内容を確認して**自分で出品ボタンを押す**

## 出品フォームのURL

| | URL |
|---|---|
| メルカリ | `https://jp.mercari.com/sell/create` |
| Yahoo!フリマ | `https://paypayfleamarket-sec.yahoo.co.jp/item/add` |

**Yahoo!フリマの出品フォームは別ドメイン**(`paypayfleamarket-sec`)にあります。
`paypayfleamarket.yahoo.co.jp/sell` は出品トップ(下書き一覧など)で、
そこから「出品する」を押すと上記の別ドメインへ移動します。
拡張は両方のドメインで動きますが、**フォームでないページではパネルにその旨を表示**します。

## サイトごとのフォーム構造(2026-08時点の調査結果)

| 項目 | メルカリ | Yahoo!フリマ |
|---|---|---|
| カテゴリ | **専用ページへ遷移** `/sell/categories` | ボトムシート(ページ内) |
| ブランド(任意) | **専用ページへ遷移** `/sell/brands`。検索欄に入力して候補から選ぶ | 未検証 |
| 商品の状態 | **専用ページへ遷移** `/sell/conditions` | ボトムシート(ページ内) |
| 配送の方法 | **専用ページへ遷移** `/sell/shipping_methods` | アコーディオン+ラジオ(業者2択) |
| 配送料の負担 | ネイティブ`<select>` | **項目なし**(全品出品者負担) |
| 発送までの日数 / 発送元 | ネイティブ`<select>` | ネイティブ`<select>` |

メルカリの3項目はページ遷移(SPAのクライアント遷移)なので、拡張は
**行をクリック → 選択肢を選ぶ →(必要なら「更新する」で確定)→ フォームへ戻る**を自動でこなします。

処理順にも依存関係があります。メルカリの**配送の方法の行は「配送料の負担」を選ぶまで出てこない**ため、
選択項目は「カテゴリ → 商品の状態 → 配送料の負担 → 配送の方法 → 発送元 → 発送までの日数」の順に、
ページ遷移型と画面内選択を混ぜて画面に出る順で埋めます。
テキストと写真は全ての遷移が終わったあと(最後)に入れます。

安全のため、確定ボタンを探すときも `出品` `購入` `支払` `削除` を含む要素は絶対にクリックしません。

## うまく埋まらないときは

サイトのDOMは予告なく変わるため、ラベル文字列から入力欄を探す方式にしていますが、
それでも外れることがあります。その場合:

1. パネルの**「フォーム構造をコピー(調整用)」**を押す(クリップボードにフォームの構造がコピーされます)
2. その内容を元に `sites/mercari.js` / `sites/yahoo.js` の `labels` や `selectors` を追記する

`selectors` に実際のCSSセレクタを書けば、ラベル探索より優先して使われます。

## 構成

```
manifest.json     MV3マニフェスト
background.js     XW-3サーバへのfetch(content scriptからは同一オリジン制約で叩けないため経由する)
content.js        出品ページ上のパネルUI(Shadow DOMに隔離)
lib/fill.js       フォーム流し込みエンジン(chrome APIに依存しない)
sites/*.js        サイトごとのラベル定義
options.html/js   XW-3のURL設定
test/             モックフォームでの検証(拡張として読み込まず単体で動く)
```

## テスト

`lib/fill.js` は chrome API を使っていないため、モックフォームで単体検証できます。

```bash
cd extension && python3 -m http.server 8799
```

ブラウザで以下を開くと、想定フォームに対する流し込み結果が左下に PASS/FAIL で表示されます。

- http://localhost:8799/test/mock-mercari.html — ネイティブselect・ラジオ・3段カスケード・file input経路
- http://localhost:8799/test/mock-yahoo.html — カスタムドロップダウン・タグEnter確定・drop専用ゾーン経路
